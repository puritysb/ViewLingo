🚀 Getting Started

Which languages are supported?

ViewLingo supports languages available in both Apple text recognition (OCR) and Translation on your Mac. Available languages depend on your macOS version.

How do I create a viewfinder? ▼
The quickest way to create a viewfinder:
  • Instant Creation: Double-tap fn + Control to create a viewfinder at your mouse position instantly
  • Alternative: You can also use the menu bar icon or app menu to create a viewfinder
The viewfinder will appear as a translucent window that you can move and resize as needed.
How do I close a viewfinder? ▼
You can close a viewfinder in several ways:
  • Press ESC key
  • Triple-click anywhere on the viewfinder
  • Click Close (✕), just outside the viewfinder
What permissions does ViewLingo need? ▼
ViewLingo requires Screen Recording permission to capture the content within your viewfinder. This is a macOS requirement for any app that captures screen content.
Privacy note: Captured images are processed on your Mac. Optional DeepL comparison in 3.0 sends only text you explicitly select and approve, never screenshots.

🌍 Languages & Translation

Which languages are supported? ▼
ViewLingo supports languages available in both Apple text recognition (OCR) and Translation on your Mac. Available languages depend on your macOS version.
How accurate are the translations? ▼

ViewLingo uses Apple's built-in translation engine on your Mac by default. Quality varies with the source and target languages, the scene, text-recognition (OCR) accuracy and the context available. Short dialogue, names and specialist terms can be mistranslated.

For 3.0, we are preparing an optional DeepL comparison using your own API key. After your explicit consent and translation request, it sends only the original text, context and terms you select. Apple remains the default for regular captures and Live. Comparing results can help you choose, but DeepL is not guaranteed to be better for every passage.

For better results, keep in mind:
  • Clear, legible text is recognized most reliably
  • Including a full sentence gives the translator more context
  • Your source-language list tells ViewLingo which languages to expect
Retry re-translates the current area whenever you like.
Can I translate offline? ▼
Yes, with Apple translation. Regular captures and Live work offline after language packs are downloaded. Optional DeepL comparison in 3.0, when available, requires an internet connection, your own API account and explicit consent.

⚡ Features & Performance

What is Live Translation Mode? ▼
Live Mode automatically retranslates content as it changes on screen, perfect for:
  • Video subtitles
  • Live streams
  • Dynamic web content
  • Scrolling documents
💡 Tip: Frame the text you want to follow, such as a subtitle line or dialogue box. Live updates when that text changes and holds steady when it doesn't.
Does ViewLingo support vertical text (Japanese, Chinese)? ▼
Yes! ViewLingo natively handles vertical text commonly found in Japanese, Chinese, and Korean content. Vertical text is automatically detected and translations render in the correct writing direction.
What happens when the translation is longer than the original text? ▼
ViewLingo uses adaptive font sizing to ensure translated text fits naturally within the original text area. It automatically adjusts font size, tries condensed fonts, and uses multi-line wrapping when needed to maintain readability.
Does ViewLingo slow down my Mac? ▼
Under normal usage, ViewLingo has minimal impact on system performance:
  • Regular Mode: Very low resource usage, processes only when you request translation
  • Live Mode: Higher resource usage due to continuous processing
ViewLingo runs on macOS 15.0 or later as a universal app, native on both Apple silicon and Intel Macs.
Can I translate text in any app? ▼
Yes! ViewLingo can translate text from any application or website, including:
  • Web browsers (Safari, Chrome, Firefox)
  • PDF readers
  • Video players
  • Games
  • Documents and presentations
  • Social media apps
The viewfinder captures whatever is visible on your screen, regardless of the source application.

🛠️ Troubleshooting

Nothing appears when I capture. Is the app broken? ▼
Usually this means the language pack for that language pair isn't installed yet. macOS does the translating, and it needs each pack downloaded once before it can work offline.
  • ViewLingo detects this and helps you download the missing pack.
  • To install manually: System Settings › General › Language & Region › Translation Languages, then download the languages you need.
  • You only need the languages you actually read plus your own — not all of them.
  • After downloading, return to ViewLingo and capture again. Apple translation then runs fully offline.
ViewLingo isn't recognizing text properly. What can I do? ▼
Try these solutions:
  • Check text clarity: Ensure the text is clearly visible and not blurry
  • Adjust viewfinder size: Make sure the entire text is within the viewfinder
  • Zoom in: Enlarging very small text on screen helps recognition
  • Check language settings: Ensure the source language is supported
I updated ViewLingo but it's not capturing anymore, even though permission is enabled. ▼
This is a known macOS behavior. When an app is updated, macOS may invalidate its screen recording permission internally, even though System Settings still shows it as "enabled." To fix this:
  1. Open System Settings > Privacy & Security > Screen Recording
  2. Find ViewLingo in the list
  3. Remove it using the − (minus) button
  4. Add it back using the + (plus) button
  5. Restart ViewLingo
Why does this happen? macOS tracks each app version with a unique cryptographic hash (CDHash). After an update, the hash changes but the permission entry may still reference the old version. Removing and re-adding the permission refreshes this association.
The app crashes or freezes. How do I fix this? ▼
  1. Restart ViewLingo: Quit and relaunch the app
  2. Check macOS version: Ensure you're running macOS 15.0 or later
  3. Disable Live Mode: If enabled, turn off Live Mode in settings
  4. Restart your Mac: Sometimes a system restart helps
  5. Reinstall: Delete and reinstall from the App Store
If problems persist, please report the issue on our GitHub Issues page.

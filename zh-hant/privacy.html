另行選擇的網站分析

僅在另行同意分析後，Google Analytics 4才統計頁面到達與App Store按鈕點擊。使用固定公開來源、媒介、廣告活動、頁面路徑和CTA位置。Google可能使用第一方Cookie並處理IP、瀏覽器和網路資訊，SDK也可能產生基本工作階段與互動事件。不傳送輸入文字、翻譯、電子郵件、客戶ID或任意URL查詢。點擊價值為0，並非購買。

此目的獨立於Google Ads和Yahoo評估，原有廣告同意不適用。拒絕、GPC/DNT及撤回會阻止後續Analytics收集，可在頁尾「網站分析設定」中變更。選擇與分析Cookie最長保留60天，不會每次造訪都延長Cookie期限。使用者與事件層級保留設為2個月，不隨活動重設；彙總報表可能保留更久。加強型評估、Google信號、詳細位置/裝置收集和廣告個人化均已關閉。不新增User-ID、客戶比對、跨裝置功能或廣告帳戶連結。

資料代表已同意的活動，並非所有訪客或不重複購買人數。內部導覽不算新到達，但重新整理、來源資訊缺失及回訪會影響次數。不將個別網站訪客與App Store購買連結。Apple廣告活動報表有延遲與隱私門檻，未顯示不等於0。

網站廣告評估

以下原有條款適用於ViewLingo Mac App。網站評估是獨立的選用功能：Google Ads評估網頁造訪和App Store按鈕點擊，Yahoo Ads（LINE Yahoo）評估已登記Yahoo廣告活動的App Store按鈕點擊。僅在您明確允許兩家提供者後載入指令碼。提供者可能使用Cookie並接收頁面和來源頁面URL、廣告活動和廣告識別碼、IP位址及瀏覽器和網路資訊。傳送的是價值為0的前往Store事件，並非購買。不傳送App螢幕、OCR、翻譯內容、輸入文字、電子郵件地址、電話號碼、客戶或交易識別碼。不使用進階比對，關閉Google廣告個人化，不新增Yahoo再行銷事件。如URL或來源位址可能包含任意輸入，則略過Yahoo評估。也不啟用Yahoo選用的localStorage副本。先前僅針對Google的同意不適用於Yahoo，須重新選擇；先前的拒絕繼續有效。選擇在瀏覽器保留180天，優先遵循瀏覽器隱私訊號。拒絕後Store連結仍可使用。可於頁尾「廣告評估設定」更改或撤回同意，撤回後卸載標籤。拒絕、封鎖、瀏覽器限制和歸因期限等可能導致評估缺漏。下載、購買和收入須於App Store Connect另行查看。

Yahoo頁面到達是另一個額外評估目的。在允許原有評估後，仍可另行允許或拒絕Yahoo廣告活動頁面到達事件。原有Store點擊同意不會自動擴大至造訪評估。此造訪價值為0，並非購買。Yahoo可能接收相同的廣告活動及廣告識別碼、IP位址和瀏覽器及網路資訊。額外選擇不含客戶識別碼，在瀏覽器保留180天，可在頁尾設定中更改或撤回而不改變Store點擊選擇。拒絕和瀏覽器隱私訊號會阻止額外事件。計數僅涵蓋符合條件且已同意的頁面到達，並非所有訪客或獨立人數。

🔒 預設本機處理，外部翻譯由您選擇。

一般擷取與Live翻譯使用Mac上的Apple翻譯。ViewLingo 2.x繼續在本機運作。以下選用DeepL連線自3.0起提供，在您自行設定並同意前保持關閉。

3.2 的選用 OpenAI 比較

OpenAI 比較是選用功能。在支援的 App Store 地區，也僅於您儲存自己的 API 金鑰並另行同意傳送後才啟用。金鑰與 DeepL 分開存於 macOS 鑰匙圈。此功能使用 API 帳戶，而非 ChatGPT 訂閱；未獲商業授權前不提供 ChatGPT 登入。

僅於點選使用 OpenAI 翻譯時，才透過 HTTPS 直接傳送所選原文、來源與目標語言、同一擷取中選定的最多五段先前上下文及五項術語。API 金鑰用於驗證，OpenAI 也會處理通訊所需的網路資訊。不傳送截圖、視窗標題、其他歷史或無關專案。Apple 翻譯與 Live 不會自動切換至 OpenAI。

請求使用 store:false，但不保證零保留。OpenAI 可能依 API 政策保留濫用監控記錄。除非您另行向 OpenAI 同意分享，否則 API 資料預設不用於訓練。提供者的帳戶條款、保留設定和 API 費用與 ViewLingo 分開適用。

App Store 地區會自動與本機允許清單核對，無須選擇國家或於每次工作階段重新確認。Storefront 不證明實際位置。在中國大陸等不支援或未確認的商店地區，OpenAI 請求會被阻止。OpenAI 也可能依實際連線地區拒絕存取；服務提供者拒絕時連線將停止。我們不收集 GPS，也不查詢 IP 地理位置服務。

即使在不支援地區，也可撤回同意並刪除金鑰。取消無法收回已傳送的請求。此 Mac 的月度權杖預算會保守預留輸入與輸出並記錄用量，但不是金額或帳戶總限額。刪除本機資料不會刪除 OpenAI 已處理的資訊。

預設Apple翻譯

Apple文字辨識在Mac上處理擷取的影像。下載所需語言包後，Apple翻譯可離線使用。一般擷取與Live不會自動切換到DeepL。我們不營運接收應用程式截圖或翻譯請求的伺服器，Mac應用程式沒有使用分析或追蹤功能。

3.0的選用DeepL比較

DeepL需要您自己的API帳號與網際網路連線。您必須儲存金鑰、同意分享文字、檢查預覽，再主動按下DeepL翻譯按鈕。開啟設定、編輯專案或開啟比較視窗不會傳送文字。請求透過HTTPS直接傳送給DeepL，同時處理驗證用的API金鑰與通訊所需的網路資訊。

  • 選定的原文與來源及目標語言
  • 僅在您啟用並選取後，同一次擷取中先前的最多5段文字
  • 您為該請求選定的最多5個術語
  • 不傳送截圖、視窗標題、完整紀錄或無關專案

DeepL帳號與資料條款

DeepL API Free / Developer可能儲存內容並用於改善模型。請勿透過此方案傳送個人資料或機密文字。目前API Pro / Growth條款排除模型訓練，但允許有限的除錯保留。提供者的條款、額度與費用獨立於ViewLingo適用。啟用連線前請閱讀最新政策。

儲存在Mac上的資訊

擷取影像、翻譯紀錄、專案與術語儲存在應用程式的本機儲存空間。API金鑰儲存在macOS鑰匙圈中。應用程式在本機記錄每月用量，以執行ViewLingo字元預算。此預算不是DeepL帳號總額度，也不包含其他應用程式的用量。我們不收集應用程式遙測資料。

您的控制選項

每次請求都由您選擇要傳送的文字與選項。上下文預設關閉。您可以取消、撤回同意、中斷連線並刪除已存金鑰。已傳送的請求無法收回，取消或逾時後仍可能計入API用量。在應用程式中刪除本機紀錄或專案不會刪除DeepL已處理的資料。關於提供者保留的資料及您的權利，請依DeepL政策聯絡DeepL。

螢幕錄製權限

macOS授予應用程式螢幕錄製權限，以擷取您選擇的區域。影像辨識在Mac上完成，選用外部比較也僅傳送文字。開發者無法透過此權限遠端存取您的螢幕。

政策更新

應用程式行為或相關要求變更時，我們會更新本頁面。本政策更新不會為現有2.x版本新增外部翻譯連線。如對ViewLingo的資料處理有疑問，請透過下方方式聯絡我們。

由您主動寄送的問題報告

在支援問題報告的版本中，您可以在 Mac 上預覽內容、取消勾選選填項目或放棄報告。報告包含 App 版本和組建編號。macOS 版本、處理器類型、錯誤代碼、語言組合、模式、各階段耗時範圍以及您填寫的說明均為選填。只有您從記錄中親自選取的句子和影像才會附上。您可以遮住影像的部分區域並預覽結果。預設不包含螢幕影像、辨識的原文、譯文或內部記錄。

檔案會儲存在您選擇的位置。開啟郵件草稿不會寄出報告。如果您將郵件寄至 admin@foundby.kr，開發者會收到您的寄件地址及所選內容，郵件服務商可能保留投遞記錄。只有開發者基於調查問題的目的能存取收到的資料。問題解決時或收件後90天內（以較早者為準），開發者會刪除郵件及附件。您可以寄信至同一地址要求立即刪除。只有另行取得您的同意後，才會將經過遮蔽的副本放入程式碼儲存庫或議題記錄中。

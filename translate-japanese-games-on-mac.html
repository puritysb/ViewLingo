A practical guide · macOS 15+

Read Japanese games
on your Mac.

When dialogue is part of the game screen, copying it into a translator isn’t always an option. Select that part of the screen with ViewLingo and read the translation over the game.

01 / SETUP

Prepare the two languages.

ViewLingo requires macOS 15 or later. During setup, allow Screen Recording so the app can read the selected area of your screen. Captured content and translations are processed on your Mac.

In ViewLingo’s language settings, choose Japanese as a source and the language you want to read as the target. This demonstration uses English. Download the required language packs when prompted; translation can work offline after they are ready.

Use the available language list on your Mac as the reference. ViewLingo supports languages that work with both Apple text recognition and translation.

Full installation and permission guide →
02 / SELECT

Start with one dialogue box.

Open a scene with clear, stationary text. Use ViewLingo’s menu bar controls to create a viewfinder, or use the default fn + Control + Option shortcut to select an area. Your shortcut may differ if you changed it in Settings.

Draw around the dialogue you want to read. Keep the selected area focused on the text rather than the entire game window. The translation appears over that part of the screen.

Start in a window. A windowed game makes it easier to position the viewfinder and reach its controls while learning the app. Do not assume every fullscreen or protected game behaves the same way.
03 / LIVE

Follow the next line.

Turn on Live mode to translate changing text in the selected region. Advance to the next dialogue and leave it visible long enough for recognition and translation. If the dialogue box moves, reposition the viewfinder.

Text that appears briefly, animated lettering and rapid scene changes are harder to read reliably. Pause or slow the dialogue when the game allows it. ViewLingo translates visible text; it does not transcribe spoken dialogue.

When the result is hard to read.

No text is recognized
Check Screen Recording permission, confirm the viewfinder covers the text and try a larger in-game text size. Blurred or decorative fonts can reduce recognition quality.
The language is missing
Check the languages offered by ViewLingo on this Mac and whether the required packs finished downloading. macOS language availability can differ between versions.
The translation gets in the way
Adjust the selected area or close the viewfinder with Escape before interacting with the game. Use a paused scene to compare the result with the original.

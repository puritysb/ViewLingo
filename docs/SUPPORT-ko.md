# ViewLingo 지원

ViewLingo 지원에 오신 것을 환영합니다! 번역 경험을 최대한 활용할 수 있도록 도와드리겠습니다.

## 🚀 빠른 시작 가이드

1. **첫 실행**
   - 첫 실행 안내에 따라 화면 녹화 권한을 허용하세요
   - 온보딩에서 언어를 고르고 필요한 언어팩을 내려받으세요

2. **기본 사용법**
   - `fn+Control+Option`을 누르고 번역할 글자 위로 드래그
   - 원문 위에 표시된 번역 읽기
   - 설정 › 일반에서 Live 모드를 켠 뒤, 뷰파인더 옆 Live 버튼으로 바뀌는 화면을 계속 번역

3. **팁**
   - 세 번 클릭, ESC, 또는 뷰파인더 바깥의 닫기(✕) 버튼으로 닫기
   - 가장자리를 드래그하여 뷰파인더 크기 조정
   - 뷰파인더를 드래그하여 이동 — 번역도 함께 따라옵니다

## ❓ 자주 묻는 질문

### 일반 질문

**Q: 번역이 나타나지 않습니다**
- 시스템 설정 > 개인정보 보호 및 보안 > 화면 녹화에서 권한이 활성화되어 있는지 확인
- 텍스트가 명확하게 보이고 너무 작지 않은지 확인
- 텍스트를 제대로 캡처하도록 뷰파인더 크기 조정 시도

**Q: 어떤 언어가 지원되나요?**
- Mac의 문자 인식(OCR)과 Apple 번역이 함께 지원하는 모든 언어를 제공합니다. 정확한 목록은 ViewLingo 설정에서 확인하세요
- 필요한 언어팩은 ViewLingo가 내려받도록 안내하며, 시스템 설정 > 일반 > 언어 및 지역 > 번역 언어에서도 관리할 수 있습니다

**Q: ViewLingo는 오프라인으로 작동하나요?**
- 네! 언어팩을 한 번 내려받으면 macOS 내장 번역 모델로 완전히 오프라인 번역합니다

**Q: 번역을 더 잘 나오게 하려면?**
- ViewLingo는 Apple의 내장 신경망 번역 엔진을 사용합니다
- 문장 전체가 들어가도록 뷰파인더를 맞추면 문맥이 풍부해집니다
- 설정에서 자주 보는 소스 언어를 추가해 두세요
- 다시 시도 버튼으로 언제든 다시 번역할 수 있습니다

### 기술적 문제

**Q: ViewLingo가 실행되지 않습니다**
- macOS 15.0 이상을 실행 중인지 확인
- Mac 재시작 시도
- MDM/기업 정책에 의해 화면 녹화 권한이 차단되었는지 확인

**Q: 번역이 느립니다**
- 번역 모델을 처음 불러올 때는 첫 번역에 조금 더 걸릴 수 있습니다
- Live 모드에서는 따라갈 글자만 뷰파인더에 담으면 가장 빠르게 갱신됩니다

**Q: 앱이 충돌하거나 멈춥니다**
- Command+Option+Esc를 사용하여 강제 종료
- 설정에서 번역 기록이 너무 크면 삭제
- 문제가 지속되면 앱 재설치

### 개인정보 및 권한

**Q: 내 화면 데이터는 안전한가요?**
- 모든 처리는 기기에서 수행됩니다
- 외부 서버로 데이터가 전송되지 않습니다
- 화면 캡처는 Mac 안에서 처리되며, 번역 기록에 보관된 캡처도 Mac을 떠나지 않습니다

**Q: 권한을 취소할 수 있나요?**
- 네, 시스템 설정 > 개인정보 보호 및 보안 > 화면 녹화로 이동
- ViewLingo 체크 해제하여 권한 취소
- 필요할 때 앱이 다시 활성화하라는 메시지를 표시합니다

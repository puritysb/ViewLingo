## 🎯 อ่านข้อความบนหน้าจอเป็นภาษาของคุณ ตรงตำแหน่งเดิม

ลากช่องมองภาพไปวางบนเกม วิดีโอ รูปภาพ PDF หรือหน้าต่างแอปใดก็ได้ ViewLingo จะจดจำข้อความแล้ววางคำแปลซ้อนทับบนต้นฉบับโดยตรงเหมือน AR ไม่ต้องคัดลอกหรือสลับแอป

### ✨ คุณสมบัติหลัก
- 🔍 **แปลด้วยช่องมองภาพ**: กด `fn+Control+Option` แล้วลากคลุมข้อความที่อยากอ่าน หรือแตะ `fn+Control` สองครั้งเพื่อเปิดช่องมองภาพตรงตำแหน่งตัวชี้ทันที เลื่อนหรือปรับขนาดเมื่อไร คำแปลก็ตามไปด้วย
- 🎨 **ภาพซ้อนทับแบบ AR ในตำแหน่งเดิม**: คำแปลถูกวาดทับข้อความต้นฉบับให้เข้ากับเค้าโครงและสี พร้อมปรับขนาดตัวอักษรอัตโนมัติให้อ่านง่ายแม้คำแปลจะยาวกว่า หากพื้นที่จำกัด เพียงวางตัวชี้ไว้ก็ดูคำแปลฉบับเต็มได้
- ⚡ **โหมด Live**: ตามทันข้อความที่เปลี่ยนไปในคำบรรยายวิดีโอ เกม สไลด์ และไลฟ์สตรีม และคงคำแปลไว้อย่างนิ่งเมื่อหน้าจอไม่เปลี่ยน ล็อกช่องมองภาพเพื่อคลิกและเลื่อนหน้าจอด้านล่างได้ขณะที่คำแปลยังแสดงอยู่
- 🎛️ **แถบเครื่องมือกะทัดรัด**: ใช้ Live ลองใหม่ และปิดได้สะดวก ใน 3.0 เมื่อเลือกเต็มหน้าจอ แถบเครื่องมือจะอยู่ด้านในโดยเว้นขอบสำหรับปรับขนาด
- 📐 **รองรับข้อความแนวตั้ง**: จดจำและแปลข้อความแนวตั้งภาษาญี่ปุ่น จีน และเกาหลี
- 🌍 **ภาษาที่ Mac ของคุณรองรับ**: ใช้ได้ทุกภาษาที่ทั้งระบบจดจำข้อความ (OCR) ของ Mac และ Apple Translation รองรับ และเพิ่มขึ้นตาม macOS การตั้งค่าครั้งแรกจะช่วยคุณดาวน์โหลดชุดภาษาเพียงครั้งเดียว จากนั้นการแปลเริ่มต้นของ Apple จะทำงานแบบออฟไลน์
- 🔒 **ออกแบบเพื่อความเป็นส่วนตัว**: การแปลเริ่มต้นของ Apple ประมวลผลบนเครื่อง แอปไม่มีการวิเคราะห์หรือติดตามการใช้งาน และต้องใช้สิทธิ์บันทึกหน้าจอ ดูรายละเอียดการเปรียบเทียบภายนอกแบบเลือกใช้ใน 3.0 ด้านล่าง

### 💡 ราคาง่ายและตรงไปตรงมา
- ซื้อครั้งเดียว ไม่มีค่าสมัครสมาชิก ตรวจสอบราคาในภูมิภาคของคุณได้ที่ App Store
- การแปลของ Apple ไม่ต้องมีบัญชี การเปรียบเทียบ DeepL แบบเลือกใช้ใน 3.0 ต้องใช้บัญชี API ของคุณเอง โดยมีค่าบริการและขีดจำกัดของผู้ให้บริการแยกต่างหาก
- ใช้เอนจินการแปลของ Apple ที่มีอยู่ใน Mac
- การแปลเริ่มต้นของ Apple ใช้งานออฟไลน์ได้หลังดาวน์โหลดชุดภาษา

### 🚀 เริ่มต้นใช้งาน
1. ดาวน์โหลดจาก Mac App Store
2. ทำตามขั้นตอนตอนเปิดครั้งแรกเพื่ออนุญาตการบันทึกหน้าจอและดาวน์โหลดชุดภาษา
3. กด `fn+Control+Option` แล้วลากคลุมข้อความที่ต้องการแปล
4. อ่านคำแปลที่แสดงอยู่บนต้นฉบับได้ทันที!

### ⌨️ แป้นพิมพ์ลัด
- `fn+Control+Option` - สร้างช่องมองภาพใหม่ (เปลี่ยนได้ในการตั้งค่า)
- แตะ `fn+Control` สองครั้ง - เปิดช่องมองภาพที่ตำแหน่งตัวชี้ทันที
- `ESC` หรือคลิกสามครั้ง - ปิดช่องมองภาพ
- ปุ่ม **Live** ข้างช่องมองภาพ - เปิด/ปิดโหมด Live

### 📋 ความต้องการของระบบ
- macOS 15.0 หรือใหม่กว่า
- แอป Universal รองรับทั้ง Mac ชิป Apple และ Mac ที่ใช้ Intel
- สิทธิ์การบันทึกหน้าจอ

### 🔐 ความเป็นส่วนตัว
การจับภาพปกติและ Live ใช้ Apple บน Mac ส่วนเวอร์ชัน 2.x ยังคงทำงานในเครื่อง ใน 3.0 คุณสามารถบันทึกคีย์ API DeepL ของตนเองในพวงกุญแจ ให้ความยินยอม แล้วสั่งเปรียบเทียบแยกต่างหากได้ ระบบส่งเฉพาะต้นฉบับที่เลือก ข้อความก่อนหน้าในภาพเดียวกันไม่เกินห้ารายการ และคำศัพท์ที่เลือกไม่เกินห้าคำ ไม่ส่งรูปภาพ ชื่อหน้าต่าง หรือประวัติทั้งหมด ประวัติและโปรเจ็กต์เก็บไว้ในเครื่อง และแอปไม่เก็บสถิติการใช้งาน โปรดอ่านเงื่อนไขข้อมูลของผู้ให้บริการ และอย่าส่งข้อมูลส่วนบุคคลหรือข้อความลับผ่าน Free / Developer ดู[นโยบายความเป็นส่วนตัว](https://puritysb.github.io/ViewLingo/privacy.html)

### 🌟 ทำไมต้อง ViewLingo?
- **ทันที**: ไม่ต้องคัดลอก-วาง ไม่ต้องสลับแอป
- **เป็นธรรมชาติ**: คำแปลซ้อนทับตามเค้าโครงต้นฉบับ
- **ส่วนตัว**: Apple ประมวลผลในเครื่องเป็นค่าเริ่มต้น การเปรียบเทียบภายนอกต้องได้รับความยินยอมและคำสั่งจากคุณ
- **ออฟไลน์**: การแปลเริ่มต้นของ Apple ไม่ต้องใช้อินเทอร์เน็ตหลังดาวน์โหลดชุดภาษา
- **ภาษาของคุณ**: หน้าตาแอปรองรับ 12 ภาษา รวมถึงภาษาไทย

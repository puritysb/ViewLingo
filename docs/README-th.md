## 🎯 อ่านข้อความบนหน้าจอเป็นภาษาของคุณ ตรงตำแหน่งเดิม

ลากช่องมองภาพไปวางบนเกม วิดีโอ รูปภาพ PDF หรือหน้าต่างแอปใดก็ได้ ViewLingo จะจดจำข้อความแล้ววางคำแปลซ้อนทับบนต้นฉบับโดยตรงเหมือน AR ไม่ต้องคัดลอก ไม่ต้องสลับแอป และเนื้อหาบนหน้าจอไม่ออกไปนอก Mac ของคุณ

### ✨ คุณสมบัติหลัก
- 🔍 **แปลด้วยช่องมองภาพ**: กด `fn+Control+Option` แล้วลากคลุมข้อความที่อยากอ่าน หรือแตะ `fn+Control` สองครั้งเพื่อเปิดช่องมองภาพตรงตำแหน่งตัวชี้ทันที เลื่อนหรือปรับขนาดเมื่อไร คำแปลก็ตามไปด้วย
- 🎨 **ภาพซ้อนทับแบบ AR ในตำแหน่งเดิม**: คำแปลถูกวาดทับข้อความต้นฉบับให้เข้ากับเค้าโครงและสี พร้อมปรับขนาดตัวอักษรอัตโนมัติให้อ่านง่ายแม้คำแปลจะยาวกว่า หากพื้นที่จำกัด เพียงวางตัวชี้ไว้ก็ดูคำแปลฉบับเต็มได้
- ⚡ **โหมด Live**: ตามทันข้อความที่เปลี่ยนไปในคำบรรยายวิดีโอ เกม สไลด์ และไลฟ์สตรีม และคงคำแปลไว้อย่างนิ่งเมื่อหน้าจอไม่เปลี่ยน ล็อกช่องมองภาพเพื่อคลิกและเลื่อนหน้าจอด้านล่างได้ขณะที่คำแปลยังแสดงอยู่
- 🎛️ **ปุ่มควบคุมที่ไม่บังข้อความ**: ปุ่ม Live, ลองใหม่ และปิด อยู่นอกพื้นที่ที่เลือก จึงไม่บังข้อความที่คุณกำลังอ่าน
- 📐 **รองรับข้อความแนวตั้ง**: จดจำและแปลข้อความแนวตั้งภาษาญี่ปุ่น จีน และเกาหลี
- 🌍 **ภาษาที่ Mac ของคุณรองรับ**: ใช้ได้ทุกภาษาที่ทั้งระบบจดจำข้อความ (OCR) ของ Mac และ Apple Translation รองรับ และเพิ่มขึ้นตาม macOS การตั้งค่าครั้งแรกจะช่วยคุณดาวน์โหลดชุดภาษาเพียงครั้งเดียว จากนั้นแปลแบบออฟไลน์ได้เลย
- 🔒 **ออกแบบเพื่อความเป็นส่วนตัว**: ประมวลผลบนอุปกรณ์ 100% ไม่ต้องมีบัญชี ไม่มีการวิเคราะห์หรือติดตาม ขอสิทธิ์เพียงอย่างเดียวคือการบันทึกหน้าจอ

### 🚀 เริ่มต้นใช้งาน
1. ดาวน์โหลดจาก Mac App Store
2. ทำตามขั้นตอนตอนเปิดครั้งแรกเพื่ออนุญาตการบันทึกหน้าจอและดาวน์โหลดชุดภาษา
3. กด `fn+Control+Option` แล้วลากคลุมข้อความที่ต้องการแปล
4. อ่านคำแปลที่แสดงอยู่บนต้นฉบับได้ทันที!

### ⌨️ แป้นพิมพ์ลัด
- `fn+Control+Option` - สร้างช่องมองภาพใหม่ (เปลี่ยนได้ในการตั้งค่า)
- แตะ `fn+Control` สองครั้ง - เปิดช่องมองภาพที่ตำแหน่งตัวชี้ทันที
- `ESC` หรือคลิกสามครั้ง - ปิดช่องมองภาพ
- ปุ่ม **Live** ข้างช่องมองภาพ - เปิด/ปิดโหมด Live

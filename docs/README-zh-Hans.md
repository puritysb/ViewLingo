## 🎯 屏幕上的文字，原地读懂

在游戏、视频、照片、PDF 或任意应用窗口上拖出一个取景框，ViewLingo 就会识别其中的文字，并像 AR 一样把译文直接叠加在原文上。无需复制，也无需切换应用。

### ✨ 主要功能
- 🔍 **取景框翻译**：按下 `fn+Control+Option`，拖过想读的文字即可。连按两下 `fn+Control`，取景框会直接出现在指针位置。移动或调整大小时，翻译也会随之更新。
- 🎨 **原位 AR 叠加**：译文贴合原文的排版与颜色，并自动调整字号，较长的译文同样清晰易读。空间不够时，将指针悬停即可查看完整译文。
- ⚡ **Live 模式**：持续跟随视频字幕、游戏、幻灯片和直播中不断变化的文字；画面不变时，译文也稳稳保持。锁定取景框后，可以在译文显示的同时点击、滚动下方内容。
- 🎛️ **不遮挡文字的控制按钮**：Live、重试和关闭按钮位于选区外侧，绝不遮挡你正在阅读的文字。
- 📐 **竖排文字支持**：可识别并翻译日文、中文、韩文的竖排文字。
- 🌍 **你的 Mac 支持的语言**：提供 Mac 文字识别（OCR）与 Apple 翻译共同支持的全部语言，并随 macOS 一同扩展。首次设置会引导你下载一次语言包，之后默认Apple翻译可离线运行。
- 🔒 **隐私优先设计**：默认Apple翻译在设备上处理，无应用分析或跟踪，需要屏幕录制权限。3.0的可选外部比较请见下方说明。

### 💡 简单透明的价格

- Apple翻译无需账户。3.0可选DeepL比较需要您自己的API账户，提供商费用与限额另行适用。

### 🚀 开始使用
1. 从 Mac App Store 下载
2. 按照首次启动的引导授予屏幕录制权限并下载语言包
3. 按下 `fn+Control+Option`，拖过要翻译的文字
4. 直接在原文上方阅读译文！

### ⌨️ 键盘快捷键
- `fn+Control+Option` - 创建新的取景框（可在设置中更改）
- 连按两下 `fn+Control` - 在指针位置立即创建取景框
- `ESC` 或连点三下 - 关闭取景框
- 取景框旁的 **Live** 按钮 - 开启/关闭 Live 模式

### 📋 系统要求
- macOS 15.0 或更高版本
- 通用应用，同时支持 Apple 芯片和 Intel 芯片的 Mac
- 屏幕录制权限

### 🔐 隐私
常规捕捉和Live使用Mac上的Apple翻译，2.x继续在本地运行。3.0推出后，您可将自己的DeepL API密钥存入钥匙串，同意后主动请求单独比较。仅发送选定原文、同次捕捉中最多5段先前文本和5个术语，不发送截图、窗口标题或完整记录。记录和项目保存在本地，不收集应用遥测。请检查提供商的数据条款，不要通过Free / Developer发送个人信息或机密文本。详见[隐私政策](https://puritysb.github.io/ViewLingo/zh-hans/privacy.html)。

### 🌟 为什么选择 ViewLingo？
- **即时**：无需复制粘贴，无需切换应用
- **自然**：译文按原文排版直接叠加显示
- **私密**：默认Apple翻译在本地处理，外部比较需要主动同意并请求
- **离线**：默认Apple翻译在下载语言包后无需联网
- **你的语言**：应用界面支持包括简体中文在内的 12 种语言

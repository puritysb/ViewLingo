## 🎯 画面の文字を、その場であなたの言語に

ゲーム、動画、写真、PDF、アプリのウインドウの上にビューファインダーをドラッグするだけ。ViewLingoが文字を認識し、翻訳を原文の真上にARのように重ねて表示します。コピーもアプリの切り替えも不要で、画面の内容がMacの外に出ることはありません。

### ✨ 主な機能
- 🔍 **ビューファインダー翻訳**: `fn+Control+Option`を押して、読みたい文字の上をドラッグ。`fn+Control`をダブルタップすれば、ポインタの位置にすぐビューファインダーが開きます。移動やサイズ変更をしても翻訳が追従します。
- 🎨 **その場に重なるARオーバーレイ**: 原文のレイアウトと色に合わせて翻訳を描き、長い訳文も読みやすい文字サイズに自動調整。スペースが足りないときは、ポインタを重ねると訳文全体を確認できます。
- ⚡ **Liveモード**: 動画の字幕、ゲーム、スライド、ライブ配信など、変化する文字を追いかけて翻訳。画面が変わらないときは表示が安定したまま保たれます。ビューファインダーをロックすれば、翻訳を表示したまま下の画面をクリックやスクロールで操作できます。
- 🎛️ **文字を隠さないコントロール**: Live・再試行・閉じるボタンは選択範囲の外側に配置。読んでいる文字を覆いません。
- 📐 **縦書き対応**: 日本語・中国語・韓国語の縦書きテキストも認識して翻訳します。
- 🌍 **お使いのMacが対応する言語**: Macの文字認識（OCR）とApple翻訳の両方が対応するすべての言語を利用でき、macOSの進化とともに増えていきます。言語パックは初回セットアップの案内に沿って一度ダウンロードするだけ。その後はオフラインで翻訳できます。
- 🔒 **プライバシー重視の設計**: 100%オンデバイス処理。アカウント、分析、トラッキングは一切なし。必要な権限は画面収録だけです。

### 🚀 始めよう
1. Mac App Storeからダウンロード
2. 初回起動の案内に沿って画面収録を許可し、言語パックをダウンロード
3. `fn+Control+Option`を押して、翻訳したい文字の上をドラッグ
4. 原文の上に表示された翻訳をそのまま読むだけ！

### ⌨️ キーボードショートカット
- `fn+Control+Option` - 新しいビューファインダーを作成（設定で変更可能）
- `fn+Control` をダブルタップ - ポインタの位置にビューファインダーをすぐ作成
- `ESC` またはトリプルクリック - ビューファインダーを閉じる
- ビューファインダー横の **Live** ボタン - Liveモードのオン/オフ

### 🔐 プライバシー
ViewLingoは個人データを一切収集・送信しません。文字認識も翻訳もすべてデバイス上で処理され、翻訳履歴はMacの中だけに保存されます。保存期間は自分で選べ、いつでも消去できます。詳細は[プライバシーポリシー](https://puritysb.github.io/ViewLingo/ja/privacy.html)をご覧ください。

### 🌟 なぜViewLingoなのか？
- **すぐに**: コピペ不要、アプリ切り替え不要
- **自然**: 翻訳が原文のレイアウトのまま重なって表示
- **プライベート**: 画面の内容がMacから出ることはありません
- **オフライン**: 言語パックさえあればインターネットなしで動作
- **使い慣れた言語で**: 日本語を含む11言語のアプリ表示に対応

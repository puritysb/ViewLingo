## 🎯 画面の文字を、その場であなたの言語に

ゲーム、動画、写真、PDF、アプリのウインドウの上にビューファインダーをドラッグするだけ。ViewLingoが文字を認識し、翻訳を原文の真上にARのように重ねて表示します。コピーやアプリの切り替えなしで読めます。

### ✨ 主な機能
- 🔍 **ビューファインダー翻訳**: `fn+Control+Option`を押して、読みたい文字の上をドラッグ。`fn+Control`をダブルタップすれば、ポインタの位置にすぐビューファインダーが開きます。移動やサイズ変更をしても翻訳が追従します。
- 🎨 **その場に重なるARオーバーレイ**: 原文のレイアウトと色に合わせて翻訳を描き、長い訳文も読みやすい文字サイズに自動調整。スペースが足りないときは、ポインタを重ねると訳文全体を確認できます。
- ⚡ **Liveモード**: 動画の字幕、ゲーム、スライド、ライブ配信など、変化する文字を追いかけて翻訳。画面が変わらないときは表示が安定したまま保たれます。ビューファインダーをロックすれば、翻訳を表示したまま下の画面をクリックやスクロールで操作できます。
- 🎛️ **コンパクトなツールバー**: Live・再試行・閉じるを手元で操作。3.0では画面いっぱいの選択でも、端のサイズ変更領域を空けて内側に配置します。
- 📐 **縦書き対応**: 日本語・中国語・韓国語の縦書きテキストも認識して翻訳します。
- 🌍 **お使いのMacが対応する言語**: Macの文字認識（OCR）とApple翻訳の両方が対応するすべての言語を利用でき、macOSの進化とともに増えていきます。言語パックは初回セットアップの案内に沿って一度ダウンロードするだけ。その後の標準Apple翻訳はオフラインで動作します。
- 🔒 **プライバシー重視の設計**: 標準のApple翻訳はデバイス上で処理します。アプリの利用分析や追跡は行わず、画面収録の権限が必要です。3.0の任意の外部比較については下記をご覧ください。

### 💡 シンプルで正直な価格
- 買い切り、サブスクリプションなし。お住まいの地域の価格は App Store でご確認ください。
- Apple翻訳はアカウント不要です。3.0の任意のDeepL比較にはご自身のAPIアカウントが必要で、提供元の料金と上限が別途適用されます。
- Mac内蔵のApple翻訳エンジンを使用
- 標準のApple翻訳は言語パックのダウンロード後、オフラインで動作します。

### 🚀 始めよう
1. Mac App Storeからダウンロード
2. 初回起動の案内に沿って画面収録を許可し、言語パックをダウンロード
3. `fn+Control+Option`を押して、翻訳したい文字の上をドラッグ
4. 原文の上に表示された翻訳をそのまま読むだけ！

### ⌨️ キーボードショートカット
- `fn+Control+Option` - 新しいビューファインダーを作成（設定で変更可能）
- `fn+Control` をダブルタップ - ポインタの位置にビューファインダーをすぐ作成
- `ESC` またはトリプルクリック - ビューファインダーを閉じる
- ビューファインダー横の **Live** ボタン - Liveモードのオン/オフ

### 📋 システム要件

- Appleシリコン搭載MacとIntel搭載Macの両方に対応したユニバーサルアプリ

### 🔐 プライバシー
通常のキャプチャとLiveはMac上のApple翻訳を使用し、2.xは引き続きローカルで動作します。3.0の提供開始後は、ご自身のDeepL APIキーをキーチェーンに保存し、同意して別の比較を依頼できます。送信するのは選択した原文、同じキャプチャ内の直前の文章を最大5件、用語を最大5件だけです。画像、ウインドウ名、履歴全体は送りません。履歴とプロジェクトはローカル保存で、アプリの利用統計は収集しません。提供元のデータ条件を確認し、Free / Developerで個人情報や機密情報を送らないでください。詳しくは[プライバシーポリシー](https://puritysb.github.io/ViewLingo/ja/privacy.html)をご覧ください。

### 🌟 なぜViewLingoなのか？
- **すぐに**: コピペ不要、アプリ切り替え不要
- **自然**: 翻訳が原文のレイアウトのまま重なって表示
- **プライベート**: 標準のApple翻訳はローカル。外部比較はご自身の同意と明示的な操作でのみ実行
- **オフライン**: 標準のApple翻訳は言語パックのダウンロード後、インターネット不要
- **使い慣れた言語で**: 日本語を含む12言語のアプリ表示に対応

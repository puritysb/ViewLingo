# ViewLingo 개인정보처리방침

- 문자 인식은 Mac에서 처리합니다. 캡처 번역의 기본 엔진은 Apple 번역이며 Live와 단축어도 Apple 번역을 사용합니다. 스크린샷과 번역 기록은 Mac에 보관합니다.
- 별도로 동의하면 연결된 외부 서비스를 일반 캡처에 사용할 수 있습니다. 선택한 서비스에는 인식한 텍스트와 출발·도착 언어가 전송됩니다. API 키는 macOS 키체인에 저장합니다.
- 선택형 OpenAI 무료 체험은 ViewLingo 중계를 통해 텍스트를 보냅니다. 비교와 체험 캡처는 일일 한도를 공유합니다. 한도가 소진되거나 서비스에 오류가 생기면 캡처를 Apple 번역으로 처리합니다.
- 수동 비교는 직접 선택한 텍스트와 옵션만 전송합니다. 지원 환경에서 Apple Private Cloud Compute를 별도로 동의해 이용할 수 있으며, Apple이 서비스 한도를 적용합니다.
- 앱에서 동의를 철회할 수 있습니다. 서비스별 전송 정보, 제공업체 방침, 웹사이트의 별도 측정 설정은 전문에서 확인할 수 있습니다.

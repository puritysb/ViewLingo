## 🎯 螢幕上的文字，就地讀懂

在遊戲、影片、照片、PDF 或任何 App 視窗上拖出一個觀景窗，ViewLingo 就會辨識其中的文字，並像 AR 一樣把譯文直接疊在原文上。不必複製，也不必切換App。

### ✨ 主要功能
- 🔍 **觀景窗翻譯**：按下 `fn+Control+Option`，拖過想讀的文字即可。連按兩下 `fn+Control`，觀景窗會直接出現在指標位置。移動或調整大小時，翻譯也會跟著更新。
- 🎨 **原位 AR 疊加**：譯文貼合原文的版面與顏色，並自動調整字級，較長的譯文也清楚易讀。空間不夠時，將指標停在上方即可查看完整譯文。
- ⚡ **Live 模式**：持續跟上影片字幕、遊戲、簡報和直播中不斷變化的文字；畫面不變時，譯文也穩穩保持。鎖定觀景窗後，可以在譯文顯示的同時點按、捲動下方內容。
- 🎛️ **不遮住文字的控制按鈕**：Live、重試和關閉按鈕位於選取範圍外側，絕不遮住你正在閱讀的文字。
- 📐 **直書文字支援**：可辨識並翻譯日文、中文、韓文的直書文字。
- 🌍 **你的 Mac 支援的語言**：提供 Mac 文字辨識（OCR）與 Apple 翻譯共同支援的所有語言，並隨 macOS 一同擴充。首次設定會引導你下載一次語言包，之後預設Apple翻譯可離線運作。
- 🔒 **隱私優先設計**：預設Apple翻譯在裝置上處理，無應用程式分析或追蹤，需要螢幕錄製權限。3.0的選用外部比較請見下方說明。

### 💡 簡單透明的價格
- 一次買斷，無訂閱。請在 App Store 查看您所在地區的價格。
- Apple翻譯不需帳號。3.0選用DeepL比較需要您自己的API帳號，提供者費用與額度另行適用。
- 使用 Mac 內建的 Apple 翻譯引擎
- 預設Apple翻譯在下載語言包後可離線運作。

### 🚀 開始使用
1. 從 Mac App Store 下載
2. 依照首次啟動的引導允許螢幕錄製權限並下載語言包
3. 按下 `fn+Control+Option`，拖過要翻譯的文字
4. 直接在原文上方閱讀譯文！

### ⌨️ 鍵盤快速鍵
- `fn+Control+Option` - 建立新的觀景窗（可在設定中更改）
- 連按兩下 `fn+Control` - 在指標位置立即建立觀景窗
- `ESC` 或連按三下 - 關閉觀景窗
- 觀景窗旁的 **Live** 按鈕 - 開啟/關閉 Live 模式

### 📋 系統需求
- macOS 15.0 或以上版本
- 通用 App，同時支援 Apple 晶片與 Intel 處理器的 Mac
- 螢幕錄製權限

### 🔐 隱私權
一般擷取與Live使用Mac上的Apple翻譯，2.x繼續在本機運作。3.0推出後，您可將自己的DeepL API金鑰存入鑰匙圈，同意後主動要求獨立比較。僅傳送選定原文、同次擷取中最多5段先前文字和5個術語，不傳送截圖、視窗標題或完整紀錄。紀錄與專案儲存在本機，不收集應用程式遙測。請檢查提供者的資料條款，不要透過Free / Developer傳送個人資料或機密文字。詳見[隱私政策](https://puritysb.github.io/ViewLingo/zh-hant/privacy.html)。

### 🌟 為什麼選擇 ViewLingo？
- **即時**：不必複製貼上，不必切換 App
- **自然**：譯文依原文版面直接疊加顯示
- **私密**：預設Apple翻譯在本機處理，外部比較需要主動同意並要求
- **離線**：預設Apple翻譯在下載語言包後不需連網
- **你的語言**：App 介面支援包含繁體中文在內的 12 種語言

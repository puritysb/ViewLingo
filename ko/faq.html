ViewLingo에 대해 알아야 할 모든 것

🚀 시작하기

어떤 언어를 지원하나요?

ViewLingo는 Mac의 Apple 문자 인식(OCR)과 번역이 함께 지원하는 언어를 제공합니다. 사용 가능한 언어는 macOS 버전에 따라 달라집니다.

뷰파인더를 어떻게 생성하나요? ▼
뷰파인더를 생성하는 가장 빠른 방법:
  • 즉시 생성: fn + Control 키를 더블탭하여 마우스 위치에 뷰파인더를 생성합니다
  • 대안: 메뉴 바 아이콘이나 앱 메뉴를 사용해서도 뷰파인더를 생성할 수 있습니다
뷰파인더는 이동하고 크기를 조절할 수 있는 반투명 창으로 나타납니다.
뷰파인더를 어떻게 닫나요? ▼
여러 가지 방법으로 뷰파인더를 닫을 수 있습니다:
  • ESC 키 누르기
  • 뷰파인더 아무 곳이나 트리플 클릭
  • 뷰파인더 바로 바깥의 닫기(✕) 버튼 클릭
ViewLingo는 어떤 권한이 필요한가요? ▼
ViewLingo는 뷰파인더 내의 콘텐츠를 캡처하기 위해 화면 녹화 권한이 필요합니다. 이는 화면 콘텐츠를 캡처하는 모든 앱에 대한 macOS 요구사항입니다.
프라이버시 참고: 캡처 이미지는 Mac에서 처리합니다. 3.0의 선택형 DeepL 비교는 직접 선택하고 동의한 텍스트만 보내며 스크린샷은 전송하지 않습니다.

🌍 언어 및 번역

어떤 언어를 지원하나요? ▼
ViewLingo는 Mac의 Apple 문자 인식(OCR)과 번역이 함께 지원하는 언어를 제공합니다. 사용 가능한 언어는 macOS 버전에 따라 달라집니다.
번역 정확도는 어떤가요? ▼

ViewLingo는 기본적으로 Mac 안에서 Apple 내장 번역 엔진을 사용합니다. 번역 품질은 원문과 번역 언어의 조합, 장면, 문자 인식(OCR)의 정확도와 주어진 문맥에 따라 달라집니다. 짧은 대사, 이름, 전문 용어는 잘못 번역될 수 있습니다.

3.0에서는 본인의 API 키로 선택형 DeepL 비교를 이용할 수 있도록 준비하고 있습니다. 명시적으로 동의하고 번역을 요청할 때만 직접 선택한 원문·문맥·용어를 전송합니다. 일반 캡처와 Live의 기본 엔진은 Apple로 유지됩니다. 결과를 비교해 판단할 수 있지만, DeepL이 모든 문장을 더 잘 번역한다는 보장은 없습니다.

더 좋은 결과를 위한 팁:
  • 또렷하게 보이는 글자일수록 더 정확하게 인식됩니다
  • 문장 전체를 담으면 번역에 필요한 문맥이 풍부해집니다
  • 소스 언어 목록을 설정해 두면 어떤 언어를 읽을지 ViewLingo가 미리 알 수 있습니다
다시 시도 버튼으로 언제든 현재 영역을 다시 번역할 수 있습니다.
오프라인에서도 번역할 수 있나요? ▼
Apple 번역은 가능합니다. 일반 캡처와 Live는 언어팩을 내려받은 후 오프라인으로 동작합니다. 3.0이 제공되면 선택할 수 있는 DeepL 비교에는 인터넷, 본인의 API 계정, 명시적 동의가 필요합니다.

⚡ 기능 및 성능

실시간 번역 모드란 무엇인가요? ▼
라이브 모드는 화면의 콘텐츠가 변경될 때 자동으로 재번역합니다. 다음과 같은 경우에 완벽합니다:
  • 비디오 자막
  • 라이브 스트림
  • 동적 웹 콘텐츠
  • 스크롤되는 문서
💡 팁: 자막 한 줄이나 대화창처럼 따라갈 글자만 뷰파인더에 담으세요. 글자가 바뀌면 번역이 갱신되고, 그대로일 때는 안정적으로 유지됩니다.
ViewLingo가 Mac을 느리게 만드나요? ▼
일반적인 사용에서 ViewLingo는 시스템 성능에 최소한의 영향을 미칩니다:
  • 일반 모드: 매우 낮은 리소스 사용량, 번역 요청 시에만 처리
  • 라이브 모드: 지속적인 처리로 인한 높은 리소스 사용량
ViewLingo는 macOS 15.0 이상에서 동작하는 유니버설 앱으로, Apple silicon과 Intel Mac 모두에서 네이티브로 실행됩니다.
모든 앱에서 텍스트를 번역할 수 있나요? ▼
네! ViewLingo는 다음을 포함한 모든 애플리케이션이나 웹사이트의 텍스트를 번역할 수 있습니다:
  • 웹 브라우저 (Safari, Chrome, Firefox)
  • PDF 리더
  • 비디오 플레이어
  • 게임
  • 문서 및 프레젠테이션
  • 소셜 미디어 앱
뷰파인더는 소스 애플리케이션에 관계없이 화면에 표시되는 모든 것을 캡처합니다.

💰 가격 및 구매

ViewLingo의 가격은 얼마인가요? ▼

App Store에서 해당 국가의 현재 가격을 확인하세요.

ViewLingo는 다음을 포함하는 일회성 구매입니다:
  • Apple 번역을 사용하는 일반 캡처와 Live
  • Mac이 지원하는 모든 언어 (Apple의 무료 언어팩 사용)
  • Apple 번역에는 계정·회원가입 불필요
  • ViewLingo 구독 요금 없음
  • 기본 Apple 번역은 로컬 처리
3.0이 제공되면 선택할 수 있는 DeepL 비교에는 본인의 API 계정이 필요합니다. DeepL 사용료와 한도는 앱 구매와 별도로 적용됩니다.
가족과 ViewLingo를 공유할 수 있나요? ▼
네! ViewLingo는 Apple의 가족 공유를 지원하므로 추가 비용 없이 최대 6명의 가족 구성원과 구매를 공유할 수 있습니다. 또한 모든 개인 Mac에 설치할 수 있습니다.
ViewLingo가 만족스럽지 않으면 어떻게 하나요? ▼
ViewLingo는 Apple의 표준 환불 정책을 따릅니다. 앱이 기대에 맞지 않으면 reportaproblem.apple.com에서 Apple에 환불을 요청할 수 있습니다.

🔒 프라이버시 및 보안

ViewLingo에서 내 데이터는 안전한가요? ▼

일반 캡처와 Live는 Apple을 사용해 로컬에서 처리하며, 앱 분석이나 추적 기능은 없습니다. 3.0이 제공되면 선택할 수 있는 DeepL 비교는 기본적으로 꺼져 있고, 본인의 API 키, 동의, 직접적인 번역 요청이 필요합니다. 보내기 전에 원문, 같은 캡처의 이전 문맥 최대 5개와 용어 최대 5개를 확인하세요. 스크린샷, 창 제목, 전체 기록은 보내지 않습니다. 제공자의 데이터 처리 조건과 사용료가 적용되며 Free / Developer로 개인 정보나 기밀 내용을 보내면 안 됩니다.

개인정보 처리방침 보기

화면 녹화 권한은 어떤가요? ▼

화면 기록 권한으로 앱은 사용자가 선택한 영역만 캡처합니다. 이미지 인식은 Mac에서 이루어집니다. 캡처 이미지는 로컬에 남고, 선택형 DeepL 비교도 선택한 텍스트만 전송합니다. 이 권한으로 개발자가 사용자의 화면에 원격 접근할 수는 없습니다.

🛠️ 문제 해결

캡처해도 아무것도 안 나옵니다. 앱이 고장 난 건가요? ▼
대개 해당 언어쌍의 언어팩이 아직 설치되지 않은 경우입니다. 번역은 macOS가 담당하며, 오프라인으로 동작하려면 언어팩을 한 번 내려받아야 합니다.
  • ViewLingo가 이 상황을 감지하고 필요한 언어팩을 내려받도록 도와 드립니다.
  • 직접 설치하려면: 시스템 설정 › 일반 › 언어 및 지역 › 번역 언어에서 필요한 언어를 내려받으세요.
  • 모든 언어가 아니라, 실제로 읽는 언어와 본인 언어만 있으면 됩니다.
  • 내려받은 뒤 ViewLingo로 돌아와 다시 캡처하면 됩니다. 이후 Apple 번역은 오프라인으로 동작합니다.
ViewLingo가 텍스트를 제대로 인식하지 못합니다. 어떻게 해야 하나요? ▼
다음 해결책을 시도해보세요:
  • 텍스트 선명도 확인: 텍스트가 선명하게 보이고 흐릿하지 않은지 확인
  • 뷰파인더 크기 조정: 전체 텍스트가 뷰파인더 내에 있는지 확인
  • 확대하기: 아주 작은 글자는 화면에서 확대하면 더 잘 인식됩니다
  • 언어 설정 확인: 소스 언어가 지원되는지 확인
ViewLingo를 업데이트했는데 화면 캡처가 안 됩니다. 권한은 허용되어 있는데요. ▼
이것은 알려진 macOS 동작입니다. 앱이 업데이트되면 시스템 설정에서는 권한이 "허용"으로 표시되더라도 macOS가 내부적으로 화면 녹화 권한을 무효화할 수 있습니다. 해결 방법:
  1. 시스템 설정 > 개인정보 보호 및 보안 > 화면 기록을 엽니다
  2. 목록에서 ViewLingo를 찾습니다
  3. − (빼기) 버튼으로 제거합니다
  4. + (더하기) 버튼으로 다시 추가합니다
  5. ViewLingo를 재시작합니다
왜 이런 일이 발생하나요? macOS는 각 앱 버전을 고유한 암호화 해시(CDHash)로 추적합니다. 업데이트 후 해시가 변경되지만 권한 항목은 여전히 이전 버전을 참조할 수 있습니다. 권한을 제거하고 다시 추가하면 이 연결이 새로고침됩니다.
앱이 충돌하거나 멈춥니다. 어떻게 고치나요? ▼
  1. ViewLingo 재시작: 앱을 종료하고 다시 실행
  2. macOS 버전 확인: macOS 15.0 이상을 실행 중인지 확인
  3. 라이브 모드 비활성화: 활성화된 경우 설정에서 라이브 모드를 끄기
  4. Mac 재시작: 때때로 시스템 재시작이 도움이 됩니다
  5. 재설치: App Store에서 삭제하고 재설치
문제가 지속되면 GitHub Issues 페이지에 문제를 보고해주세요.

별도로 선택하는 웹 분석

별도 분석 동의 후에만 Google Analytics 4로 동의 후 페이지 조회·랜딩 도달·App Store 버튼 클릭을 집계합니다. 고정된 공개 유입 채널·매체·캠페인·페이지 경로·CTA 위치를 사용합니다. Google이 자체 쿠키를 사용하고 IP·브라우저·네트워크 정보를 처리할 수 있으며 SDK가 기본 세션·참여 이벤트를 생성할 수도 있습니다. 입력 텍스트·번역·이메일·고객 ID·임의 URL 쿼리는 보내지 않습니다. 클릭은 가치 0이며 구매가 아닙니다.

이 목적은 Google Ads·Yahoo 측정과 별개이며 기존 광고 동의로 허용되지 않습니다. 거부·GPC/DNT·철회 시 이후 Analytics 수집을 막습니다. 하단 “웹 분석 설정”에서 선택을 바꿀 수 있습니다. 동의 선택과 분석 쿠키는 최대 60일이며 방문할 때마다 쿠키 만료를 연장하지 않습니다. 사용자·이벤트 수준 보존은 활동에 따른 갱신 없이 2개월로 설정했으며 합산 보고서는 더 오래 남을 수 있습니다. 향상된 측정·Google Signals·세부 위치/기기 수집·광고 개인화는 껐습니다. User-ID·고객 데이터 매칭·기기 간 연결·광고 계정 연결은 추가하지 않습니다.

집계는 동의한 활동이며 전체 방문자나 고유 구매자 수가 아닙니다. 동의 후 문서당 페이지 조회를 한 번 기록하며 내부 이동도 포함합니다. ViewLingo 내부 탐색은 새 도달로 세지 않지만 새로고침·누락된 유입 페이지 정보·재방문은 수치에 영향을 줍니다. 개별 웹 방문자와 App Store 구매를 연결하지 않습니다. Apple 캠페인 보고는 지연·개인정보 임계치가 있으며 미표시를 0으로 해석하지 않습니다.

웹사이트 광고 측정

아래 기존 항목은 ViewLingo Mac 앱의 개인정보 처리방침입니다. 웹사이트 측정은 별도 선택 기능입니다. Google Ads는 웹 방문·App Store 버튼 클릭을, Yahoo Ads(LINE Yahoo)는 등록된 Yahoo 캠페인의 App Store 버튼 클릭을 측정합니다. 두 제공자에 명시적으로 허용한 후에만 스크립트를 불러옵니다. 각 제공자는 쿠키를 사용하고 페이지·참조 페이지 URL, 캠페인·광고 식별자, IP 주소와 브라우저·네트워크 정보를 받을 수 있습니다. 보내는 이벤트는 가치 0의 Store 이동이며 구매가 아닙니다. 앱 화면·OCR·번역 내용·입력 텍스트·이메일·전화번호·고객 및 거래 식별자는 보내지 않습니다. 고급 매칭은 사용하지 않고 Google 광고 개인화는 끄며 Yahoo 리타기팅 이벤트는 추가하지 않습니다. URL이나 참조 주소에 임의 입력값이 있을 수 있으면 Yahoo 측정은 생략합니다. Yahoo의 선택적 localStorage 복사도 사용하지 않습니다. 기존 Google 전용 동의는 Yahoo 동의로 전이하지 않고 새 선택을 받으며, 기존 거부는 유지합니다. 선택은 브라우저에 180일간 저장하고 브라우저 개인정보 보호 신호를 우선합니다. 거부해도 모든 Store 링크를 사용할 수 있습니다. 하단 “광고 측정 설정”에서 동의를 변경·철회할 수 있고 철회 시 태그를 종료합니다. 거부·차단·브라우저 제약·귀속 기간 등으로 측정이 누락될 수 있습니다. 다운로드·구매·매출은 App Store Connect에서 별도로 확인해야 합니다.

Yahoo 랜딩 도달은 별도의 추가 측정 목적입니다. 기존 측정을 허용한 뒤에도 Yahoo 캠페인 랜딩 도달 이벤트는 따로 허용하거나 거부할 수 있습니다. 기존 Store 클릭 동의는 방문 측정 동의로 자동 확대하지 않습니다. 가치 0의 방문이며 구매가 아닙니다. Yahoo는 같은 캠페인·광고 식별자, IP 주소와 브라우저·네트워크 정보를 받을 수 있습니다. 추가 선택은 고객 식별자 없이 브라우저에 180일간 저장되며 하단 설정에서 Store 클릭 선택을 바꾸지 않고 변경·철회할 수 있습니다. 거부와 브라우저 개인정보 보호 신호는 추가 이벤트를 차단합니다. 집계는 조건을 충족한 동의 후 페이지 도달이며 전체 방문자나 고유 인원수가 아닙니다.

3.2의 내 API 키를 사용하는 OpenAI 비교

OpenAI 비교는 선택형입니다. 지원 App Store 지역에서도 본인의 OpenAI API 키 저장과 별도 전송 동의 전까지 비활성화됩니다. 키는 DeepL과 분리하여 macOS 키체인에 저장합니다. ChatGPT 구독이 아닌 API 계정을 사용하며, 상용 승인을 확보하지 않은 ChatGPT 웹 로그인은 제공하지 않습니다.

OpenAI로 번역 버튼을 직접 누른 경우에만 선택 원문, 출발·도착 언어, 같은 캡처에서 선택한 이전 문맥 최대 5개와 용어 최대 5개를 HTTPS로 OpenAI에 직접 전송합니다. API 키로 인증하며 OpenAI는 통신에 필요한 네트워크 정보도 처리합니다. 스크린샷·창 제목·다른 기록·무관한 프로젝트는 보내지 않습니다. 기본 Apple 번역과 Live는 자동으로 OpenAI로 전환되지 않습니다.

store:false로 요청하지만 무보관을 보장하지 않습니다. OpenAI는 API 정책에 따라 악용 방지 로그를 보관할 수 있습니다. OpenAI에서 별도로 공유에 동의하지 않는 한 API 데이터는 기본적으로 학습에 사용되지 않습니다. 제공자의 계정 약관·보관 설정·API 요금은 ViewLingo와 별도로 적용됩니다.

App Store 지역을 로컬 허용 목록과 자동 대조하며 국가 선택이나 세션별 재확인을 요구하지 않습니다. Storefront는 실제 위치를 증명하지 않습니다. 중국 본토 등 미지원 또는 미확인 스토어에서는 OpenAI 요청을 차단합니다. 실제 접속 지역에 따라 OpenAI가 이용을 거부할 수도 있으며, 제공자의 거부 시 연결을 중지합니다. GPS를 수집하거나 IP 위치 조회 서비스에 접속하지 않습니다.

미지원 지역에서도 동의를 철회하고 키를 삭제할 수 있습니다. 취소해도 이미 전송한 요청을 회수할 수는 없습니다. 이 Mac의 월별 토큰 예산은 입력·출력을 보수적으로 예약하고 사용량을 기록하며, 금액 한도나 계정 전체 한도가 아닙니다. 로컬 데이터 삭제로 OpenAI에서 이미 처리한 정보까지 삭제되지는 않습니다.

선택형 OpenAI 무료 체험

ViewLingo 3.2의 무료 체험 비용은 개발자가 부담합니다. 지원 지역에서 서비스가 운영되는 동안 내 API 키 대신 무료 체험을 직접 선택하고 별도로 전송에 동의해 사용할 수 있습니다. 이 Mac에서 하루 최대 10회의 새 비교 요청을 로컬에서 세며 UTC 00:00(한국 오전 9시)에 초기화합니다. 이는 soft limit이며 계정 전체의 보장된 권리가 아닙니다. 캐시 결과는 차감하지 않지만 전송 후 취소·응답 유실은 차감될 수 있습니다. 체험은 변경·중단·종료될 수 있으며 유료 API 키로 자동 전환하지 않습니다.

체험에서는 미리 본 원문·언어·선택 문맥 최대 5개·용어 최대 5개가 Cloudflare에 호스팅된 ViewLingo 중계를 거쳐 OpenAI로 전송됩니다. 개발자 키는 서버에만 보관하며 사용자의 API 키는 중계에 보내지 않습니다. 화면 이미지·창 제목·앱 계정·지속적인 설치 식별자는 보내지 않습니다. Apple 기본 번역과 Live는 로컬 처리를 유지합니다.

중계는 텍스트를 메모리에서 처리하고 번역 내용을 의도적으로 로그나 저장소에 보관하지 않습니다. Cloudflare와 OpenAI는 서비스 제공·보호에 필요한 네트워크 메타데이터를 처리합니다. 미지원·미확인 지역을 차단하기 위해 Cloudflare의 접속 국가 정보를 사용하며 클라이언트가 주장한 국가는 신뢰하지 않습니다. 완전 익명이나 제공자의 무보관을 보장하지 않습니다. 위의 OpenAI API 보관 및 기본 학습 제외 정책이 적용됩니다. 프로젝트 합계 비용 감시는 앱 분석과 구분하며 사용자 행동 추적을 추가하지 않습니다.

체험 동의와 일일 요청 기록은 로컬에 보관하고 BYOK의 동의·키·사용량과 분리합니다. 내 키를 삭제하지 않고 체험 동의를 철회할 수 있습니다. 체험 API 요금은 개발자가 부담하며 내 API 키의 사용료는 사용자 부담입니다.

체험을 사용할 수 없으면 ViewLingo는 기존 Apple 번역이 있을 때 이를 표시합니다. 체험은 직접 재개할 수 있습니다. 서비스가 제거된 뒤에도 연결 설정에서 체험 전송 동의를 철회할 수 있습니다.

기본 Apple 번역

Apple 문자 인식은 캡처 이미지를 Mac에서 처리합니다. 필요한 언어팩을 내려받으면 Apple 번역을 오프라인으로 사용할 수 있습니다. 일반 캡처와 Live가 자동으로 DeepL로 전환되지는 않습니다. 기본 Apple 번역은 스크린샷이나 번역 요청을 개발자 서버로 보내지 않습니다. 위의 선택형 체험 중계는 별도 동의를 받은 경로입니다. Mac 앱에는 분석이나 추적 기능이 없습니다.

3.0의 선택형 DeepL 비교

DeepL을 사용하려면 본인의 API 계정과 인터넷 연결이 필요합니다. 키 저장, 텍스트 전송 동의, 미리보기 확인 후 DeepL 번역 버튼을 직접 눌러야 합니다. 설정이나 비교 창을 열거나 프로젝트를 편집하는 것만으로 텍스트가 전송되지 않습니다. 요청은 HTTPS로 DeepL에 직접 전달되며, 인증용 API 키와 통신에 필요한 네트워크 정보가 함께 처리됩니다.

  • 선택한 원문과 출발·도착 언어
  • 직접 활성화하고 선택한 같은 캡처의 이전 문맥 최대 5개
  • 해당 요청에 직접 선택한 용어 최대 5개
  • 스크린샷, 창 제목, 전체 기록, 관련 없는 프로젝트는 전송하지 않음

DeepL 계정과 데이터 처리 조건

DeepL API Free / Developer는 내용을 저장하거나 모델 개선에 사용할 수 있습니다. 이 요금제로 개인 정보나 기밀 텍스트를 보내지 마세요. 현재 API Pro / Growth 조건은 모델 학습을 제외하지만 제한적인 디버깅 보관을 허용합니다. 제공자의 약관, 한도, 사용료는 ViewLingo와 별도로 적용됩니다. 연결 전에 최신 정책을 확인하세요.

Mac에 저장되는 정보

캡처 이미지, 번역 기록, 프로젝트와 용어는 앱의 로컬 저장소에 보관합니다. API 키는 macOS Keychain에 저장합니다. ViewLingo 문자 예산을 지키기 위해 월별 사용량 기록을 로컬에 보관합니다. 이 예산은 DeepL 계정 전체의 사용 한도가 아니며 다른 앱의 사용량을 포함하지 않습니다. 앱 사용 통계는 수집하지 않습니다.

사용자가 제어하는 항목

매 요청마다 보낼 텍스트와 옵션을 직접 고릅니다. 문맥 전송은 기본적으로 꺼져 있습니다. 요청 취소, 동의 철회, 연결 해제, 저장한 키 삭제가 가능합니다. 이미 전송된 요청은 회수할 수 없으며 취소하거나 시간이 초과되어도 API 사용량에 포함될 수 있습니다. 앱에서 로컬 기록이나 프로젝트를 삭제해도 DeepL이 이미 처리한 데이터까지 삭제되지는 않습니다. 제공자가 보관한 데이터와 관련 권리는 DeepL 정책에 따라 문의하세요.

화면 기록 권한

macOS는 선택한 영역을 캡처하도록 앱에 화면 기록 권한을 부여합니다. 이미지 인식은 Mac에서 이루어지며, 선택형 외부 비교도 텍스트만 보냅니다. 개발자는 이 권한으로 사용자의 화면에 원격 접근할 수 없습니다.

정책 업데이트

앱 동작이나 관련 요구사항이 바뀌면 이 페이지를 갱신합니다. 이 정책 변경만으로 기존 2.x 버전에 외부 번역 연결이 추가되지는 않습니다. ViewLingo의 데이터 처리에 관한 문의는 아래 연락처로 보내 주세요.

사용자가 직접 보내는 문제 보고

문제 보고를 지원하는 버전에서는 Mac에서 보고서를 미리 보고 선택 항목을 빼거나 취소할 수 있습니다. 앱 버전과 빌드는 항상 포함됩니다. macOS 버전, CPU 종류, 오류 코드, 언어쌍, 모드, 단계별 소요 시간 구간과 직접 쓴 설명은 선택 항목입니다. 기록에서 직접 고른 문장과 이미지만 첨부하며 이미지 일부를 가리고 결과를 확인할 수 있습니다. 화면 이미지, OCR 원문, 번역문, 내부 로그는 기본 보고에 포함되지 않습니다.

파일은 선택한 위치에 저장됩니다. 메일 초안을 열어도 발송되지 않습니다. admin@foundby.kr로 직접 발송하면 개발자는 보낸 사람 주소와 선택한 내용을 받으며 메일 제공자에게 전송 기록이 남을 수 있습니다. 수신 자료에는 개발자만 문제 조사 목적으로 접근합니다. 메일과 첨부는 문제 해결 시점과 수신 후 90일 중 먼저 도래하는 시점에 삭제합니다. 같은 주소로 요청하면 즉시 삭제합니다. 별도 동의가 있을 때만 가린 사본을 저장소나 이슈에 남깁니다.

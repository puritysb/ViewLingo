웹사이트 광고 측정

아래 기존 항목은 ViewLingo Mac 앱의 개인정보 처리방침입니다. 웹사이트 측정은 별도 선택 기능입니다. Google Ads는 웹 방문·App Store 버튼 클릭을, Yahoo Ads(LINE Yahoo)는 등록된 Yahoo 캠페인의 App Store 버튼 클릭을 측정합니다. 두 제공자에 명시적으로 허용한 후에만 스크립트를 불러옵니다. 각 제공자는 쿠키를 사용하고 페이지·참조 페이지 URL, 캠페인·광고 식별자, IP 주소와 브라우저·네트워크 정보를 받을 수 있습니다. 보내는 이벤트는 가치 0의 Store 이동이며 구매가 아닙니다. 앱 화면·OCR·번역 내용·입력 텍스트·이메일·전화번호·고객 및 거래 식별자는 보내지 않습니다. 고급 매칭은 사용하지 않고 Google 광고 개인화는 끄며 Yahoo 리타기팅 이벤트는 추가하지 않습니다. URL이나 참조 주소에 임의 입력값이 있을 수 있으면 Yahoo 측정은 생략합니다. Yahoo의 선택적 localStorage 복사도 사용하지 않습니다. 기존 Google 전용 동의는 Yahoo 동의로 전이하지 않고 새 선택을 받으며, 기존 거부는 유지합니다. 선택은 브라우저에 180일간 저장하고 브라우저 개인정보 보호 신호를 우선합니다. 거부해도 모든 Store 링크를 사용할 수 있습니다. 하단 “광고 측정 설정”에서 동의를 변경·철회할 수 있고 철회 시 태그를 종료합니다. 거부·차단·브라우저 제약·귀속 기간 등으로 측정이 누락될 수 있습니다. 다운로드·구매·매출은 App Store Connect에서 별도로 확인해야 합니다.

Yahoo 랜딩 도달은 별도의 추가 측정 목적입니다. 기존 측정을 허용한 뒤에도 Yahoo 캠페인 랜딩 도달 이벤트는 따로 허용하거나 거부할 수 있습니다. 기존 Store 클릭 동의는 방문 측정 동의로 자동 확대하지 않습니다. 가치 0의 방문이며 구매가 아닙니다. Yahoo는 같은 캠페인·광고 식별자, IP 주소와 브라우저·네트워크 정보를 받을 수 있습니다. 추가 선택은 고객 식별자 없이 브라우저에 180일간 저장되며 하단 설정에서 Store 클릭 선택을 바꾸지 않고 변경·철회할 수 있습니다. 거부와 브라우저 개인정보 보호 신호는 추가 이벤트를 차단합니다. 집계는 조건을 충족한 동의 후 페이지 도달이며 전체 방문자나 고유 인원수가 아닙니다.

🔒 기본 번역은 로컬에서, 외부 번역은 직접 선택할 때만

일반 캡처와 Live 번역은 Mac의 Apple 번역을 사용합니다. ViewLingo 2.x는 계속 로컬에서 동작합니다. 아래의 선택형 DeepL 연결 안내는 3.0이 제공될 때부터 적용되며, 직접 설정하고 동의하기 전에는 비활성화됩니다. 이 정책은 3.0이 이미 출시되었다는 안내가 아닙니다.

기본 Apple 번역

Apple 문자 인식은 캡처 이미지를 Mac에서 처리합니다. 필요한 언어팩을 내려받으면 Apple 번역을 오프라인으로 사용할 수 있습니다. 일반 캡처와 Live가 자동으로 DeepL로 전환되지는 않습니다. 앱의 스크린샷이나 번역 요청을 받는 자체 서버를 운영하지 않으며, Mac 앱에는 분석이나 추적 기능이 없습니다.

3.0의 선택형 DeepL 비교

DeepL을 사용하려면 본인의 API 계정과 인터넷 연결이 필요합니다. 키 저장, 텍스트 전송 동의, 미리보기 확인 후 DeepL 번역 버튼을 직접 눌러야 합니다. 설정이나 비교 창을 열거나 프로젝트를 편집하는 것만으로 텍스트가 전송되지 않습니다. 요청은 HTTPS로 DeepL에 직접 전달되며, 인증용 API 키와 통신에 필요한 네트워크 정보가 함께 처리됩니다.

  • 선택한 원문과 출발·도착 언어
  • 직접 활성화하고 선택한 같은 캡처의 이전 문맥 최대 5개
  • 해당 요청에 직접 선택한 용어 최대 5개
  • 스크린샷, 창 제목, 전체 기록, 관련 없는 프로젝트는 전송하지 않음

DeepL 계정과 데이터 처리 조건

DeepL API Free / Developer는 내용을 저장하거나 모델 개선에 사용할 수 있습니다. 이 요금제로 개인 정보나 기밀 텍스트를 보내지 마세요. 현재 API Pro / Growth 조건은 모델 학습을 제외하지만 제한적인 디버깅 보관을 허용합니다. 제공자의 약관, 한도, 사용료는 ViewLingo와 별도로 적용됩니다. 연결 전에 최신 정책을 확인하세요.

DeepL 개인정보 처리방침 · DeepL API 약관

Mac에 저장되는 정보

캡처 이미지, 번역 기록, 프로젝트와 용어는 앱의 로컬 저장소에 보관합니다. API 키는 macOS Keychain에 저장합니다. ViewLingo 문자 예산을 지키기 위해 월별 사용량 기록을 로컬에 보관합니다. 이 예산은 DeepL 계정 전체의 사용 한도가 아니며 다른 앱의 사용량을 포함하지 않습니다. 앱 사용 통계는 수집하지 않습니다.

사용자가 제어하는 항목

매 요청마다 보낼 텍스트와 옵션을 직접 고릅니다. 문맥 전송은 기본적으로 꺼져 있습니다. 요청 취소, 동의 철회, 연결 해제, 저장한 키 삭제가 가능합니다. 이미 전송된 요청은 회수할 수 없으며 취소하거나 시간이 초과되어도 API 사용량에 포함될 수 있습니다. 앱에서 로컬 기록이나 프로젝트를 삭제해도 DeepL이 이미 처리한 데이터까지 삭제되지는 않습니다. 제공자가 보관한 데이터와 관련 권리는 DeepL 정책에 따라 문의하세요.

화면 기록 권한

macOS는 선택한 영역을 캡처하도록 앱에 화면 기록 권한을 부여합니다. 이미지 인식은 Mac에서 이루어지며, 선택형 외부 비교도 텍스트만 보냅니다. 개발자는 이 권한으로 사용자의 화면에 원격 접근할 수 없습니다.

정책 업데이트

앱 동작이나 관련 요구사항이 바뀌면 이 페이지를 갱신합니다. 이 정책 변경만으로 기존 2.x 버전에 외부 번역 연결이 추가되지는 않습니다. ViewLingo의 데이터 처리에 관한 문의는 아래 연락처로 보내 주세요.

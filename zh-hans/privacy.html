另行选择的网站分析

仅在另行同意分析后，Google Analytics 4才统计同意后的页面浏览、页面到达与App Store按钮点击。使用固定公开来源、媒介、广告系列、页面路径和CTA位置。Google可能使用第一方Cookie并处理IP、浏览器和网络信息，SDK也可能生成基本会话与互动事件。不发送输入文字、翻译、电子邮件、客户ID或任意URL查询。点击价值为0，并非购买。

此目的独立于Google Ads和Yahoo衡量，原有广告同意不适用。拒绝、GPC/DNT及撤回会阻止后续Analytics收集，可在页脚“网站分析设置”中更改。选择与分析Cookie最长保留60天，不会每次访问都延长Cookie期限。用户与事件级保留设为2个月，不随活动重置；汇总报告可能保留更久。增强型衡量、Google信号、详细位置/设备收集和广告个性化均已关闭。不添加User-ID、客户匹配、跨设备功能或广告账号关联。

数据代表已同意的活动，并非所有访客或独立购买人数。同意后每个文档记录一次页面浏览，包括内部导航。ViewLingo内部导航不算新到达，但刷新、来源信息缺失及回访会影响次数。不将个别网站访客与App Store购买关联。Apple广告系列报告存在延迟和隐私阈值，未显示不等于0。

网站广告衡量

以下原有条款适用于ViewLingo Mac应用。网站衡量是独立的可选功能：Google Ads衡量网页访问和App Store按钮点击，Yahoo Ads（LINE Yahoo）衡量已登记Yahoo广告系列的App Store按钮点击。仅在您明确允许两家提供商后加载脚本。提供商可能使用Cookie并接收页面和来源页面URL、广告系列和广告标识符、IP地址及浏览器和网络信息。发送的是价值为0的前往Store事件，并非购买。不发送应用屏幕、OCR、翻译内容、输入文字、邮件地址、电话号码、客户或交易标识符。不使用高级匹配，关闭Google广告个性化，不添加Yahoo再营销事件。如URL或来源地址可能包含任意输入，则跳过Yahoo衡量。也不启用Yahoo可选的localStorage副本。之前仅针对Google的同意不适用于Yahoo，需重新选择；之前的拒绝继续有效。选择在浏览器保存180天，优先遵循浏览器隐私信号。拒绝后Store链接仍可使用。可在页脚“广告衡量设置”中更改或撤回同意，撤回后卸载标签。拒绝、屏蔽、浏览器限制和归因期限等可能导致衡量缺失。下载、购买和收入须在App Store Connect单独查看。

Yahoo页面到达是另一个额外衡量目的。在允许原有衡量后，仍可另行允许或拒绝Yahoo广告系列页面到达事件。原有Store点击同意不会自动扩大至访问衡量。此访问价值为0，并非购买。Yahoo可能接收相同的广告系列及广告标识符、IP地址和浏览器及网络信息。额外选择不含客户标识符，在浏览器保留180天，可在页脚设置中更改或撤回而不改变Store点击选择。拒绝和浏览器隐私信号会阻止额外事件。计数仅涵盖符合条件且已同意的页面到达，并非所有访客或独立人数。

3.2 使用自有 API 密钥的 OpenAI 对比

OpenAI 对比是可选功能。在支持的 App Store 地区，也仅在您保存自己的 API 密钥并另行同意发送后才启用。密钥与 DeepL 分开存于 macOS 钥匙串。此功能使用 API 账户，而非 ChatGPT 订阅；未获商业授权前不提供 ChatGPT 登录。

仅在点击使用 OpenAI 翻译时，才通过 HTTPS 直接发送所选原文、源语言与目标语言、同一捕捉中选定的最多五段先前上下文及五项术语。API 密钥用于身份验证，OpenAI 也会处理通信所需的网络信息。不发送截图、窗口标题、其他历史或无关项目。Apple 翻译与 Live 不会自动切换至 OpenAI。

请求使用 store:false，但不保证零保留。OpenAI 可能根据 API 政策保留滥用监控日志。除非您另行向 OpenAI 同意共享，否则 API 数据默认不用于训练。提供商的账户条款、保留设置和 API 费用与 ViewLingo 分开适用。

App Store 地区会自动与本地允许列表核对，无需选择国家或在每次会话中重新确认。Storefront 不证明实际位置。在中国大陆等不支持或未确认的商店地区，OpenAI 请求会被阻止。OpenAI 也可能根据实际连接地区拒绝访问；服务商拒绝时连接将停止。我们不收集 GPS，也不查询 IP 地理位置服务。

即使在不支持地区，也可以撤回同意并删除密钥。取消无法收回已发送的请求。此 Mac 的月度令牌预算会保守预留输入与输出并记录用量，但不是金额或账户总限额。删除本地数据不会删除 OpenAI 已处理的信息。

可选 OpenAI 免费试用

在支持的地区，ViewLingo 3.2 在服务可用期间提供由开发者承担费用的免费试用。您可主动选择试用来替代自己的 API 密钥，并单独同意发送文本。此 Mac 在本地每天记录最多 10 次新对比请求，于 UTC 00:00 重置。这是软限制，不是账户范围内的保证额度。缓存结果不计次，但发送后取消或回复丢失可能计次。试用可能调整、暂停或终止，绝不会自动切换到付费 API 密钥。

试用仅将预览原文、语言、最多五段所选上下文和五项术语通过 Cloudflare 托管的 ViewLingo 中转服务发送至 OpenAI。开发者密钥仅保存在服务器，您的 API 密钥不会发送到中转服务。不发送截图、窗口标题、应用账户或持久安装标识符。Apple 默认翻译与 Live 保持本地处理。

中转服务在内存中处理文本，不主动将翻译内容写入日志或存储。Cloudflare 和 OpenAI 处理提供及保护服务所需的网络元数据。使用 Cloudflare 的接入国家信息屏蔽不支持或未知地区，不信任客户端自行声明的国家。这不保证完全匿名或提供商零保留；上述 OpenAI API 保留及默认不用于训练的政策仍适用。项目总费用监控不同于应用分析，不添加用户行为跟踪。

试用同意及每日记录保存在本地，与 BYOK 同意、密钥和用量分开。您可撤销试用同意而不删除自己的密钥。试用 API 费用由开发者承担，自有 API 密钥费用仍由用户承担。

试用不可用时，如果已有 Apple 译文，ViewLingo 会显示该译文。您可以手动恢复试用。服务移除后，仍可在连接设置中撤回试用的发送同意。

默认Apple翻译

Apple文字识别在Mac上处理捕捉的图像。下载所需语言包后，Apple翻译可离线使用。常规捕捉和Live不会自动切换到DeepL。默认Apple翻译不会将截图或翻译请求发送至开发者服务器。上述可选试用中转是单独征得同意的路径。Mac应用没有使用分析或跟踪功能。

3.0的可选DeepL比较

DeepL需要您自己的API账户和互联网连接。您必须保存密钥、同意分享文本、检查预览，再主动点击DeepL翻译按钮。打开设置、编辑项目或打开比较窗口不会发送文本。请求通过HTTPS直接发送给DeepL，同时处理用于认证的API密钥及通信所需的网络信息。

  • 选定的原文及源语言和目标语言
  • 仅在您启用并选择后，同一次捕捉中之前的最多5段文字
  • 您为该请求选定的最多5个术语
  • 不发送截图、窗口标题、完整记录或无关项目

DeepL账户与数据条款

DeepL API Free / Developer可能保存内容并用于改进模型。请勿通过此计划发送个人信息或机密文本。当前API Pro / Growth条款排除模型训练，但允许有限的调试保留。提供商的条款、限额及费用独立于ViewLingo适用。启用连接前请阅读最新政策。

DeepL隐私政策 · DeepL API条款

保存在Mac上的信息

捕捉图像、翻译记录、项目和术语保存在应用的本地存储中。API密钥保存在macOS钥匙串中。应用在本地记录每月用量，以执行ViewLingo字符预算。此预算不是DeepL账户总限额，也不包含其他应用的用量。我们不收集应用遥测数据。

您的控制选项

每次请求都由您选择要发送的文本与选项。上下文默认关闭。您可以取消、撤回同意、断开连接并删除已存密钥。已发送的请求无法撤回，取消或超时后仍可能计入API用量。在应用中删除本地记录或项目不会删除DeepL已经处理的数据。有关提供商保留的数据及您的权利，请依据DeepL政策联系DeepL。

屏幕录制权限

macOS授予应用屏幕录制权限，以捕捉您选择的区域。图像识别在Mac上完成，可选外部比较也仅发送文本。开发者无法通过该权限远程访问您的屏幕。

政策更新

应用行为或相关要求变化时，我们会更新本页面。本政策更新不会为现有2.x版本添加外部翻译连接。如对ViewLingo的数据处理有疑问，请通过下方方式联系我们。

由您主动发送的问题报告

在支持问题报告的版本中，您可以在 Mac 上预览内容、取消勾选可选项目或放弃报告。报告包含应用版本和构建号。macOS 版本、处理器类型、错误代码、语言对、模式、各阶段耗时区间以及您填写的说明均为可选。只有您从历史记录中亲自选择的语句和图像才会被附上。您可以遮盖图像的部分区域并预览结果。默认不包含屏幕图像、识别的原文、译文或内部日志。

文件保存在您选择的位置。打开邮件草稿不会发送报告。如果您将邮件发送至 admin@foundby.kr，开发者会收到您的发件地址及所选内容，邮件服务商可能保留投递记录。仅开发者为排查问题而访问收到的资料。问题解决时或收件后90天内（以较早者为准），开发者会删除邮件及附件。您可以写信至同一地址要求立即删除。只有获得您的另行同意后，才会将经过遮盖的副本放入代码仓库或问题记录中。
